# User guide

1. Serve the repo (e.g. XAMPP) and open `koala/index.html`.
2. Iteration 1 shows self-test results plus a playable human-vs-bot Tic-Tac-Toe.
3. Tap a cell (min 44px targets); status line announces turns and results; `Restart` starts a new solo game.
